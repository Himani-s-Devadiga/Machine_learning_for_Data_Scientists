# 🚀 Machine Learning for Data Scientists

A structured **16-week learning journey from Machine Learning fundamentals to Data Scientist-level concepts**, with a focus on understanding concepts, implementing them in Python, practicing on datasets, and building end-to-end projects.

This repository documents my learning journey through **Machine Learning, Statistics, Data Analysis, Model Evaluation, Feature Engineering, Explainability, Anomaly Detection, and Time Series ML**.

---

## 🎯 Goal

The goal of this journey is to build a strong foundation in Machine Learning and gradually develop the skills required to work as a **Data Scientist**.

My learning approach is:

> **Learn → Understand → Implement → Practice → Evaluate → Explain**

I am focusing not only on learning algorithms, but also on understanding **when to use them, how to evaluate them, and why a model succeeds or fails.**

# 🧠 Learning Approach

For each major Machine Learning algorithm, I aim to understand:

1. **What problem does it solve?**
2. **How does it work intuitively?**
3. **What mathematics/statistics does it use?**
4. **When should I use it?**
5. **What are its important hyperparameters?**
6. **How should it be evaluated?**
7. **What happens when it fails?**

The objective is to move beyond simply knowing how to call a Scikit-learn function.
